# Unified Structure Manager

A PowerShell tool to export, preview, recreate, and fix file/folder structures with full metadata preservation.

## Features

- **Export** folder & file structure to CSV (optional date filter – e.g., only items before 2019-01-01)
- **Preview** what would be recreated without making changes
- **Recreate** the exact structure (folders, empty files, timestamps) from CSV
- **Fix** missing files caused by invalid characters (brackets, colons, etc.)
- **Graphical user interface** (GUI) for easy path/date selection, with settings saved in `config.json`
- Detailed logging and error reports
